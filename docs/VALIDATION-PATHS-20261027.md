# 本地输入输出路径验收 · 2026-10-27

版本：Desktop Data Studio 0.2.3-m1。范围为本机客户端，未做账号同步或服务器发布。

## 操作约定

- 主界面分别显示完整输入路径和输出目录，可选中复制；长路径自动换行。
- 文件、文件夹、ZIP/7z/7zip/RAR 共用“选择数据源”窗口。可浏览磁盘、回到桌面、粘贴完整路径、使用当前文件夹，或 Ctrl/Shift 多选。按实际文件类型识别文件与目录，工厂及业务格式继续由用户选择、原工具校验。
- 混合文件/文件夹或多个文件夹自动逐项执行；纯文件可以合并校验。DCP 文件夹递归及压缩包处理沿用已接入原工具。
- 当前本地工作区记住上次输入目录、有效的选中来源及输出目录。取消选择不改变记忆；路径失效后回到桌面。重启不会猜测清洗方式，用户需确认对应操作。
- 首次输出默认 Windows 当前用户的桌面，使用系统已知文件夹定位；用户可更改并保存偏好。
- 成功清洗后自动保存原文件。CP 沿用首个真实 Lot 和时间目录；保留原文件名、内容及目录结构，重名追加序号，不覆盖已有输出。共享 FT 报告保留原 ZIP/报告形式。
- 内部历史和外部保存副本分开保留。图表、预览及再次导出使用内部原件；外部副本修改不改变历史。任务创建时固定输出位置，后续更改目录只影响新任务。
- 输出不得落在原始输入文件夹或内部历史目录中。复制中断不发布半成品；保存失败保留已完成的内部结果并显示警告，可从历史另存。
