# 运行日志与操作可见性 · 0.2.9-m1

CP 的其他清洗/分析操作始终展开；FT 工厂菜单保持原工具对齐。提交清洗、重跑或派生 PAT 成功加入队列后，进入历史的“处理中”页并清空旧搜索/筛选。串行运行策略不变。

处理中任务下方显示独立日志面板，跟随当前运行任务；队列结束后保留本次最后任务的状态、日志和结果入口。向上滚动暂停跟随，可回到最新或复制当前日志。完整日志留在各自任务目录。

原生 FT 独立进程补上与原 GUI CleanerWorker 一致的 INFO 日志处理器，输出真实的读取文件、计算完成等信息；不改解析器或统计规则。计算组件标记更新为 studio-engine-20261027.3，CP/FT PYZ 和 Python 依赖未变化。

日志接口只接受已登记任务 ID，通过内部固定路径找到该任务日志，不接受用户路径。每次最多读取64KiB，按字节游标增量读取，处理 UTF-8 跨块、日志切换/缩短和任务终态。前端只在处理中页读取，单个请求完成后再调度下一次刷新；最多保留1000行及60000字符，不生成工作表预览，不以日志数量推算百分比。
