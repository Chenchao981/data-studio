# Data Studio 0.3.5：可编辑输入和输出路径

2026-10-29。本机桌面程序版本0.3.5，固定CPython 3.13.17及计算引擎 `studio-engine-20261029.1`。

输入和输出路径支持直接编辑及粘贴。输入可分行填写多个文件/文件夹，兼容资源管理器复制的带双引号路径；点击“应用输入路径”登记并选中，Ctrl+Enter也可应用。输出点击“应用输出路径”或Enter保存为默认位置；Escape/“取消修改”恢复已应用值。应用按钮仅在编辑时显示。

未应用的路径修改会阻止开始清洗，避免静默使用旧输入或旧输出。错误直接显示在路径下方；失败保留原输入登记和原默认输出。空输入应用后只清空本次列表；真实文件、既有任务和历史不删除。完全相同的规范路径重复粘贴只登记一次，不按Lot/Wafer身份删除不同文件。

只接受现存本机绝对路径，输入最多100行，输出必须是单个已存在的文件夹，继续拒绝UNC、相对路径及内部历史工作区作为输出；任务创建时仍执行原输入/输出重叠、格式、身份和规格校验。未创建目录会明确提示先创建或另选。当前输出路径修改不重定向已创建的任务。

可信工作台新增 `applyInputPaths({text})` 与 `applyOutputPath({text})` 两个显式提交操作。清洗继续只消费登记ID，未增加任意文件读取接口；不可信页面继续被桥接层拒绝。
