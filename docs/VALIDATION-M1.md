## 修复的集成问题

1. 真实输入不允许进入模拟路径；必须明确选择启用的工厂/操作。
2. Windows进度文件替换遭临时占用时，阶段提示降级至日志，不影响业务计算结果。阶段不变时不重复写进度。
3. ZIP内CSV.GZ指定只读模式，避免预览误以写模式打开临时流。
4. 原始工作表不按通用表头猜测量行；规格、单位、表头及公式保留原行序。
5. 真实取消覆盖与成功回执的竞态，退出用Windows Job回收本客户端计算进程树。
6. 规则选择区不再被布局压缩，输出文件列表默认折叠，错误摘要和完整执行详情分开显示。
