# 工作台简化与默认路径 · 2026-10-27

版本：0.2.6-m1。沿用现有框架，仅更新本机客户端。

## 最终行为

- 移除工作台、结果页的演示入口和“真实分析结果”切换按钮，生产界面只显示真实输入及真实历史。生产前端不再加载或打包演示表格、演示图表模块。
- 按用户最新要求，每次启动客户端清空待分析列表。仍记住上次输入文件夹位置；本次导入可包含多个文件，后续导入替换当前列表。
- 列表支持单项“移除”和“清空列表”。仅修改待分析列表，不删除原文件、结果、历史或后台任务，历史仍可重新执行。
- 设置页增加“更改输出目录”，与工作台共享同一默认目录，保存后跨重启生效。没有配置时默认 Windows 桌面；已配置目录失效时保留路径并阻止新任务，不静默回退桌面。已创建任务的输出位置不随之后设置变更。
- 输入登记使用路径索引查询，工作台只返回当前批次，历史检索在分页前过滤演示记录。旧输入登记继续用于历史重跑及导出保护，不受待分析列表清空影响。

## 验证

- 38 项自动测试覆盖历史独立性、移除、清空、启动重置、默认目录持久化、失效目录、已创建任务的输出位置，以及旧输入的导出保护。
- 原生 Qt 测试通过真实文件/文件夹选择器导入并移除、清空；输出目录对话框返回值在测试中注入，验证设置页按钮、取消选择及工作台同步。关闭并重建窗口后，输入列表为空，输入目录与输出默认值保留。
- 华虹 DCP ZIP 实际清洗成功；三个 CSV 自动保存到指定位置并与内部历史原件 SHA-256 一致。修改后续默认目录未影响已创建任务。清空并重启后，历史结果仍可打开。
- 打包 EXE 在独立工作区验证无演示入口、历史结果、任务选择器、亮暗主题和小窗口；无前端脚本异常。首屏脚本约 261.79 kB，生产构建不再包含演示模块资源；未据此推断启动耗时改善比例。
