# Data Studio 0.3.6：CP箱线散点图与按需重绘

2026-10-29。本轮按用户确认只调整现有CP图表页。入口仍为成功CP清洗记录/结果的“查看CP图表”，打开本机Cockpit；默认显示“箱线散点图”组合图，初始选一个参数，可手动选择多个或全选。

“其他图形”默认全部未选。原有BIN总览、Pareto、良率趋势、箱体图、散点图、Wafer Mapping、区域分析、失效叠加、Wafer Summary、Cpk/超限、数据表均保留，在选择后点击“重新绘制”才显示并执行。选择区通过表单统一提交，逐项勾选不触发服务端重算；移除项目同样在重绘后生效。参数/批次/片号修改后保留已应用图表并提示重绘；原有多Lot规格隔离守卫保留，防止跨Lot误用限值。

Streamlit页签本身会预计算隐藏内容，本轮对每个可选页面增加真实执行条件；默认不会生成另外11类图表/表格。组合PNG按参数与显示范围缓存，缓存键使用完整数据列的哈希，避免框架对大DataFrame默认抽样哈希造成陈旧图像。仅对可选图形统一提交，不把所有筛选控件放进冻结的表单。

组合图复用固定CP包的Lot/Wafer分组、批次颜色、单位/规格读取、逐片四分位数及1.5-IQR箱须、聚焦与完整纵轴规则，叠加全部有限测量值。包含Fail Bin和重复测量；空值/非数值/无穷值不画点；确定性抖动只改变X，不改变Y。聚焦仅改变视窗，范围外数量和规格仍标注。固定CP/FT包没有重建，其他图形继续执行原实现。
