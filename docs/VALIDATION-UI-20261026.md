# 本地客户端 v0.2.1：交互优化与验证

日期：2026-10-26。范围为本机 Desktop Data Studio；未启用账号同步，未修改或发布服务器。CP、FT 清洗算法和固定计算包未变。

## 使用流程

1. **清洗工作台**：直接点击 CP/FT、工厂和清洗操作。只有一个明确清洗入口的工厂自动选中；有多种模式时由用户选择。PAT、良率等保留在“更多清洗与分析”。
2. **导入**：选择文件、文件夹或拖入数据后自动选中；文件对话框记住本次会话上次位置。输入列表支持搜索，每页50项、跨页选择，单批最多100项。展示最近1000项登记，更早登记仍可用于历史重跑。
3. **清洗**：开始前提示文件类型不匹配、多个文件夹不能合并等问题。提交后自动转入历史记录，查看排队、进度和结果。
4. **历史与结果**：按 CP/FT、状态、文件名或操作搜索；筛选先于最近100条限制执行。任务、工作表选择支持搜索、分页、方向键和 Esc，弹层根据可见区域调整方向与高度。支持从结果返回历史。

本地历史位置沿用 `%LOCALAPPDATA%/NCE/DesktopDataStudio-M0`。未迁移、清空用户历史。输入列表的近期记录提示不代表该输入从未清洗。

## 卡顿处理及观测

- 常用 CP/FT 与工厂选择改为直接点击，结果选择改为网页内搜索弹层，减少原生下拉弹窗依赖。
- 输入列表分页及稳定组件引用，避免每次选择重绘近千行；工具目录只缓存展示信息。创建任务和执行时仍独立读取清单、验证哈希。
- 后台状态刷新合并重复请求，保留末次更新；结果表格不再反复创建主题，切换工作表时忽略旧请求返回。

| 本机测量 | 优化前 | 优化后 |
|---|---:|---:|
| 登记997项输入时实际渲染行数 | 997 | 50 |
| 同场景页面节点数 | 23,154 | 1,209 |
| 连续20次 CP/FT 切换的最大观测耗时 | 321.2 ms | 两轮分别67.5、84.8 ms |
| 工具目录热缓存30次平均耗时 | 10.54 ms | 0.108 ms |

两侧多数 CP/FT 切换约33 ms。切换及弹层测量包含等待两个动画帧，不等于纯计算耗时；不是多机、严格控制负载的性能承诺。打包客户端最终20次工作表弹层打开为23.7–46.4 ms，未发现界面脚本异常。
