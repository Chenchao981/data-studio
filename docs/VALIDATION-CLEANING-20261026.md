# 本地客户端数据清洗验收（2026-10-26）

本轮按用户要求优先验证数据清洗。下拉菜单卡顿、UI 操作流程、账号同步和服务器发布不在本轮范围。

## 结论与修复

54 个真实数据场景符合预期：52 个成功，2 个华虹 TD 反例按预期拒绝。76 张输出表、11,539,039 个单元格与原工具结果一致，无新增预览索引警告。计数包含表头及部分 PAT 场景，不代表 54 种工厂格式，也不代表全量生产数据验收。

发现并修复捷敏 XLSX 入口遗漏：原 FT 包已支持 XLS/XLSX 动态格式，但客户端 FT-ALL 和 RAW-PAT 的文件类型登记仅含 XLS。此前直接选 XLSX 会在提交前被拒绝；目录内的 XLSX 也不能正确计入输入清单。现两种格式均参与输入校验、来源数量和哈希记录，原解析及计算算法未修改。

开发目录和本机便携客户端计算组件已更新为 `studio-engine-20261026.1`。Python 保持 3.13.17，CP/FT 原计算包未更换。本轮不重新验收界面交互性能。

本机 `dist/DesktopDataStudio` 的 14,426 个固定组件文件已全部核验。通过该目录内的独立计算组件，追加测试直接选择捷敏 XLSX 与日月新 XML-XLS 两份原始文件（前述新增对账使用文件夹输入）；均成功，且再次逐格对账一致。此项验证的是便携计算组件和任务流程，不是重新操作冻结 EXE 界面的验收。启动入口仍为 `启动DataStudio.bat`；10 月 23 日的旧 ZIP 保留不变，本轮没有发布新的服务器下载包。

## 自动化与异常边界

- 原 CP 源码清洗相关测试：159 通过，6 跳过（原测试指定的本地样例未提供）；旧 PyQt5 相关 `test_rar_input.py` 未纳入。本轮客户端真实 Lion RAR 场景另已通过。
- 原 FT 源码非 GUI 测试：294 通过、2 失败。失败是旧测试仍要求新增参数、不同 Bias 条件必须拒绝，与 v2.26.10 动态规则冲突；原测试文件未改，不能写成原 FT 测试全绿。
- 针对上述差异，用原测试的独立人工样本、当前发行包另跑 7 项检查：新增参数、不同条件、单位证据分别保留；单位维度冲突、无效规格拒绝；PAT 条件分列，错误来源不产生半成品。7 项通过。
- Studio 与本地桥接自动化：31 通过，含 XLS/XLSX 混合目录完整计入来源清单的新回归测试。
- 每个成功的客户端场景检查输出哈希、结果预览行数边界、任务结束状态，以及重开本地数据库后历史仍可读取；两个预期失败场景不暴露结果。

原工具源码工作区存在未提交修改，本轮未改动这些文件。上述源码测试与固定发行包的真实数据对账分别记录，不以源码测试代替发行包验证。

CSV 业务身份保持字符串精确比较，不把片号前导零数值化；工作簿比较表名、尺寸、公式文本、单元格数值和数字格式。跨原工具结果的数值容差为相对 `1e-10`、绝对 `1e-15`；电基独立原始数值比较为零容差，原工具 Excel 回读为相对 `1e-14`、绝对零。
