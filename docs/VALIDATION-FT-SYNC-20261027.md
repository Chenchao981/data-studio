已 fetch 并核对 `Chenchao981/data_IGBT_multiples` 的 `origin/main`：`6e7ffbb`，发行版本 v2.26.15。采用该提交已发布的 `ft_data_cleaner.pyz`，SHA256 为 `aea282892c771254ec1d85ec21fdbab241667c0bef6ffd1e5b162f3f494acc3f`，与远程 Git 文件逐字节相同。归档含 102 个成员（含目录），所有 Python 文件可编译；非 Python 文件只有依赖说明，没有原始业务数据、结果、缓存或密钥。

- 上海捷敏 DC：名称由 FT-ALL 改为 DC，保留旧内部代码以支持历史重跑。使用新版动态 PowerTECH / QA 解析和产品、批次规则。
- 独立 DVDS：新增 QA DVDS 清洗入口，支持 XLS/XLSX 完整报告与明细导出、递归目录或单文件。不会调入 DC 清洗器。
- RG：补齐 CSV/XLS/XLSX，按文件内容识别 BIFF/OOXML，包括后缀误写为 CSV 的 Excel；双 DIE 数值和原单位保持不变。
- PAT：沿用新版原始数据 PAT，按动态参数、条件、单位及规格分别统计。
- 上海捷敏图表：改用与清洗一致的原生 v2.26.15 计算包，补齐 XLSX 来源指纹及提交合同。可选原始文件，由 Studio 放入受管临时目录后交给原图表流程；输出静态散点图、箱体图及统计 JSON。
- 新建任务界面隐藏已被原生功能替代的旧清洗/PAT 入口，内部兼容代码保留。旧完成记录的输出不会改写；重跑创建新任务，使用当前输入和当前规则。

与此前原生包对比，业务文件变更全部位于上海捷敏模块；日月新、电基、杰群、集佳等代码已经相同。本轮另回归日月新 XML-XLS 和电基 dj11。CP、平台 FT 兼容包以及 Python 3.13.17 / 计算依赖的固定版本和哈希不变。
