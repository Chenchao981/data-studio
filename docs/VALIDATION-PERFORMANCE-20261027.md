# v0.3.1 功能、性能与稳定性检查

结论：本次本机测试没有发现工厂卡片改版造成性能退步，保留当前设计。没有修改生产 UI、清洗算法、并发数、历史或默认路径；版本仍为0.3.1。新增可复用的性能测量和验收规范。

## 对照结果

Windows 本机、官方 CPython 冻结客户端、默认软件渲染、可见窗口、独立工作区，串行测量。对照为工作台版0.3.0与当前0.3.1；各3次连续启动，每次60次 CP/FT 切换和60次工厂选择，新版另测120次搜索。结束时页面均为 visible/focused。数据来自 `artifacts/performance-20261027/baseline/` 和 `current/`。

| 测量项 | 0.3.0 | 0.3.1 |
|---|---:|---:|
| 连续启动中位数 | 1.123秒 | 1.065秒 |
| CP/FT切换 p95，180次 | 227.7ms | 67.6ms |
| 工厂选择 p95，180次 | 155.8ms | 113.7ms |
| 工厂搜索 p95，360次 | 无该功能 | 99.5ms |
| 脚本长任务大于50ms / 前端异常 | 0 / 0 | 0 / 0 |

新版各轮交互 p95 均低于200ms；这是 DOM 确认及两次动画帧的实验室代理时间，不是正式 INP。变化是本次测试观测值，不能据此承诺所有电脑提升同样比例。启动不是重启机器后的冷启动。

回收垃圾后渲染器 JS 堆分别约2.42 MiB和2.55 MiB，各3轮一致；该数值不包含 Qt、Chromium、计算子进程或整个客户端内存，也不构成长时间无泄漏证明。新版6秒空闲采样中，渲染器主线程占用约0.019%–0.024%，不代表系统总 CPU。

## 扩容、窗口与真实工作流

- CP/FT 各20家临时布局工厂，1440×960、920×620，亮暗主题共8组；每组20次搜索，p95 为52.0–107.4ms。全部通过搜索、选择保持、键盘 Enter、无横向溢出和区域高度限制检查。生产目录没有增加模拟工厂。
- 原生窗口100次尺寸调整、4次最大化/还原，并实际切换到两台显示器（缩放150%、125%）。10次采样均非空白，渲染进程终止次数为0；最大 JS 定时器间隔55.4ms，无意外页面重载。程序化几何测试不能穷尽所有显示驱动和人工拖动条件。
- 已安装的 EXE 在独立工作区重跑真实上海捷敏 DVDS 样本 `NCEAP60ND30AG(M)-2G00_NCEG52609229_DVDS.xlsx`。从重跑到完成日志的观测流程14.272秒，142个100ms定时器样本，额外延迟 p95=10.1ms、最大14.3ms，长任务和前端异常均为0。该时间包含界面检查，不等于纯解析耗时。
- 冻结客户端六个 FT 工厂菜单、CP/FT切换记忆、处理中日志、结果查看、输出设置、窄窗和暗色通过。
- 渲染策略、日志、工作流、本地列表、路径与安全检查：19 passed、1 skipped；跳过项为 Windows 无符号链接创建权限，不能将该项声称为通过。

## 测试边界与复用

初始隐藏窗口测量受到帧调度与窗口关闭方式干扰，`before/`、`before-complete/` 不纳入正式对照；已修正为可见窗口。20家工厂初次测量的数组跨 Qt 返回格式失败，改为 JSON 传输后完成最终测试，使用 `factories20-final/` 回执。最终真实冻结客户端回执位于 `real-frozen/`；窗口与单元检查在 `resize/`、`pytest.log`。

本次没有重新对账全部 CP/FT 格式，也没有测整棵进程树的资源峰值、小时级耐久或大批量排队；这些不属于本次“无退步”结论的覆盖范围。后续按 [功能、性能、稳定性验收](QUALITY-GATES.md) 执行；业务必需功能保留，影响速度的非必要效果优先删减。
