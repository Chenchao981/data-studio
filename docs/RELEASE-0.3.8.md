# Data Studio 0.3.8：图表隐藏CONT类参数

2026-10-30。CP交互图表和FT参数图片统一隐藏CONT、CONT_TD、CONT@G、CONT@S、CONT@Gref、CONT2及其单位后缀；匹配忽略大小写、首尾空白和全角字符。CONTENT、CONTINUITY、DISCONT等不同名称保留，不按数值是否恒定判断参数有效性。

过滤发生在图表参数选择及绘制之前。CP默认选择、全选、重新绘制和已有应用条件均执行过滤；FT散点图与箱体图的聚焦/全范围图片及图片统计索引使用同一目录。只剩CONT项目时明确提示没有可绘图参数。原始文件、清洗结果、测量值、规格、Lot/Wafer、Bin和良率均不改写；历史图片和PAT报表不批量修改。本次是图表参数可见性更新，不修改PAT统计算法或清洗规则。

应用版本0.3.8，计算组件studio-engine-20261030.1。保持固定CPython 3.13.17和三个原CP/FT PYZ包，更新本仓库的图表适配代码。旧清洗历史的包哈希仍匹配，可重新打开CP图表；FT需重新生成图表图片。
