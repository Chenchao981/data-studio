# CP / FT 独立工作台 · 0.3.0-m1

侧边栏提供 CP 工作台、FT 工作台、任务进度、清洗结果、历史记录和设置。主区移除 CP/FT 大卡片，工厂和操作改为顶部横向排列，所有操作直接可见，FT 图表仍单独分区。宽屏将输入输出与待处理列表并排显示；窄窗自动上下排列。

CP 和 FT 使用独立的会话草稿，分别保留工厂、功能、输入列表、勾选和合并方式。切换不清空另一工作台，清空某工作台不删除原始文件或另一工作台的输入。已有登记的 source ID 仍通过 Core 校验并创建任务；不把文件名或扩展名推断为工厂。默认输出路径继续使用设置中的保存值。客户端重新打开时两边输入均为空，历史保留。

新任务仍串行执行并进入任务进度页，真实日志、完成/取消状态和结果入口保留。侧边栏任务进度可随时打开；页面和工作台切换回到页面顶部。没有改变清洗器、计算包或输入输出合同，计算组件仍为 studio-engine-20261027.3。

验证：

- TypeScript 和前端生产构建通过。
- 原生 Qt 文件选择器导入真实上海捷敏 DVDS 输入，在 CP 侧另登记一个仅用于界面验证的文本文件；三次往返切换验证工厂、功能、输入、合并选项分别保留，清空 CP 后 FT 输入仍可执行。
- 真实 DVDS 清洗成功；运行时日志、自动进入处理中、结果打开和重启历史通过，两边重启输入均为空。
- 冻结客户端检查六个 FT 工厂菜单、CP/FT 配置记忆、独立侧边栏入口、真实任务重跑及滚动日志、结果选择、亮暗主题、1000×760 和920×620布局。
- 本次为界面与会话状态调整，未重新验收全部工厂数据格式。历史和默认路径在本机更新前备份并核对。
