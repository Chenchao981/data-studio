# Data Studio 独立项目

2026-10-29 从 CP-FT-data-analysis 导出桌面工作台和必需的离线计算依赖，建立独立 Git 历史。来源提交和离线源文件列表见 `engine_support/SOURCE_FILES.json`。旧 PYMS 仓库作为迁移前参考，不作为运行或构建依赖。

## 保留内容

CP/FT 工厂与操作入口、文件/递归目录/压缩包输入、默认输出路径、本地任务排队和滚动日志、历史结果、本地图表，以及华虹 PAT 按兼容产品输出一个 Excel 的修复。原始数据、用户历史和输出均保留在原位置，无需搬进项目目录。

## 与 PYMS 手动关联

1. 在 Data Studio 独立分支修复并验证本地行为，记录引擎版本及输入输出对账结果。
2. 由负责人选择需要同步的适配器/计算规则，手动移植至 PYMS 对应模块；两仓库不自动拉取或部署。
3. 在 PYMS 自己的测试环境验证上传、权限、FTP、Worker 和接口契约。桌面测试通过不代表服务器测试通过。
4. 分别记录版本和部署结果，可各自回滚。不要将本机历史数据库、账号配置和真实输入数据作为代码同步。

## 固定组件与版本

应用源代码、依赖锁定文件、组件固定哈希及许可收集脚本由本仓库 Git 管理。当前计算组件、Python 依赖及第三方许可随本地离线安装包分发，并用 SHA-256 核验；安装包位于 `release/v0.3.3/`。尚无 GitHub Release 引擎下载资产、自动下载脚本或企业下载点。

新开发机按根目录 README 运行 `setup.ps1`，从已验证安装目录复制完整 `engines/` 到项目根目录，再使用 `packaging/prepare_engines.py --source-only` 核验并刷新离线适配代码。干净 clone 不包含引擎和业务样本，不能直接宣称可运行。运行环境、编译结果和测试数据不进入 Git。

应用保留原 `%LOCALAPPDATA%\NCE\DesktopDataStudio-M0` 工作区，避免分裂个人历史。今后若改变存储格式，必须显式迁移并保持可回滚。
